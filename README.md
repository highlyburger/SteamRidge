# Steam Ridge

**Steam Ridge** is a modern Steam game launcher designed to make managing and launching your games simple, clean, and convenient.

## ✨ Features

* 🎮 Launch your Steam games from one place
* 📚 Organize and manage your game library
* 🖥️ Modern and clean user interface
* ⚡ Fast game launching
* 📥 Download manager with progress tracking
* 📊 View download speed and progress
* 🖼️ Game icons and artwork
* 🔧 Easy-to-use interface

## 🚀 Getting Started

### Requirements

* Windows 10 or newer
* Steam installed on your computer
* .NET Runtime required by the application

### Installation

1. Download the latest release.
2. Extract the files if they are provided as a ZIP.
3. Run `SteamRidge.exe`.
4. Add or select your Steam games.
5. Launch your games directly through Steam Ridge.
